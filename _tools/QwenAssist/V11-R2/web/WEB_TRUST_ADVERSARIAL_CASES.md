## 12. 验证逻辑示例

```python
def evaluate_source_credibility(observation: WebObservation) -> float:
    """计算来源可信度 0-1"""
    score = 0.5  # 基础分
    
    # 来源类型加分
    if observation.source_credibility == SourceCredibility.OFFICIAL:
        score += 0.4
    elif observation.source_credibility == SourceCredibility.AUTHORITY:
        score += 0.3
    elif observation.source_credibility == SourceCredibility.SEO_SPAM:
        score -= 0.5
    
    # 时间衰减
    if observation.cache_age_hours:
        age_factor = max(0, 1 - observation.cache_age_hours / 168)  # 7天
        score *= age_factor
    
    # 提示注入惩罚
    if observation.has_prompt_injection:
        score = 0
    
    return max(0, min(1, score))
```
