# CityNexus — 文案指南 (Copy Guide)

**生成时间**: 2026-09-13 00:15  
**适用范围**: 所有用户可见的中文和英文文案  
**用途**: 确保产品语气、格式、风格的一致性

---

## 1. 产品语气 (Tone & Voice)

### 核心原则

**友好但专业 (Friendly but Professional)**
- ✅ "建议您提前 30 分钟出发，避免迟到"
- ❌ "你必须早点走，不然会迟到"（过于强硬）
- ❌ "亲，记得早点出发哦~"（过于随意）

**简洁清晰 (Concise & Clear)**
- ✅ "网络超时，请重试"
- ❌ "由于网络连接超时导致无法完成操作，请您检查网络后重新尝试"

**积极正向 (Positive)**
- ✅ "已为您保存更改"
- ❌ "你没有丢失数据"

### 人称使用

**中文**:
- 使用"您"（尊称）而非"你"
- 使用"我们"代表产品团队
- ✅ "我们已为您保存"
- ❌ "我已保存"

**英文**:
- 使用 "you"（直接）
- 使用 "we" 代表产品团队
- ✅ "We've saved your changes"
- ❌ "The system has saved"

## 2. 错误信息格式

### 结构

```
标题（简短描述问题）
正文（解释原因 + 建议操作）
按钮（明确可执行动作）
```

### 示例

**网络错误**:
```
标题：网络连接失败
正文：无法连接到服务器，请检查网络设置后重试
按钮：重试 / 取消
```

**权限错误**:
```
标题：无权访问
正文：您没有权限查看此内容，请联系管理员
按钮：联系管理员 / 关闭
```

**数据加载失败**:
```
标题：加载失败
正文：无法加载行程信息，可能是数据已过期或网络问题
按钮：刷新 / 查看缓存
```

## 3. 成功信息格式

### 结构

```
确认（已完成的动作）
结果（带来的价值）
后续（可选的下一步）
```

### 示例

**保存成功**:
```
标题：已保存
正文：您的行程更改已保存
后续：继续编辑 / 返回
```

**预订成功**:
```
标题：预订确认
正文：您已成功预订 {{hotelName}}，确认邮件已发送至 {{email}}
后续：查看订单 / 添加至日历
```

## 4. 警告与风险提示

### 风险等级

**高风险（红色）**:
- ✅ "⚠️ 承诺面临风险"
- ✅ "立即行动，避免损失"
- 使用场景：错过航班、酒店取消期限临近

**中风险（橙色）**:
- ⚠️ "请注意"
- ⚠️ "建议尽快处理"
- 使用场景：时间紧张、价格可能变化

**低风险（黄色）**:
- ℹ️ "温馨提示"
- ℹ️ "供您参考"
- 使用场景：天气变化、交通状况

### 示例

**高风险**:
```
⚠️ 您的航班将在 2 小时后起飞
当前路程需 60 分钟，建议立即出发
[查看路线] [稍后提醒]
```

**中风险**:
```
⚠️ 此报价将在 30 分钟后过期
当前价格：¥1,200
[立即预订] [刷新价格]
```

**低风险**:
```
ℹ️ 今天下午可能有雨
建议携带雨伞或调整户外活动
[查看天气] [调整行程]
```

## 5. 中英文混排规则

### 空格规则

**中文前后加空格**:
- ✅ "使用 Google Maps 导航"
- ❌ "使用 Google Maps 导航"（无空格）
- ❌ "使用  Google Maps  导航"（过多空格）

**标点符号**:
- 中文使用全角标点：，。！？
- 英文使用半角标点：,.!?
- 括号内为英文时，使用半角括号：()

### 专有名词处理

**保持英文**:
- Check-in / Check-out
- PlanVersion
- JourneyLeg
- Commitment
- MVP
- API

**已广泛使用的中文**:
- 行程（Journey）
- 活动（Activity）
- 预订（Booking）
- 承诺（Commitment）

### 示例

**正确**:
```
请在 Check-in 时间前到达酒店
您的 PlanVersion 已保存
点击 OK 按钮确认
```

**错误**:
```
请在登记入住时间前到达酒店（过度翻译）
您的计划版本已保存（技术术语应保留英文）
点击确定按钮确认（OK 是专有名词）
```

## 6. 数字与单位

### 数字格式

**中文**:
- 使用阿拉伯数字：30 分钟、120 元
- 大数字使用万/亿：1.5 万元（而非 15000 元）

**英文**:
- 使用阿拉伯数字：30 min, $120
- 大数字使用 K/M: 1.5K (1500), 2M (2000000)

### 时间格式

**中文**:
- 24 小时制：14:30、23:00
- 日期：2026 年 9 月 13 日
- 相对时间：30 分钟后、2 小时前

**英文**:
- 12 小时制带 AM/PM: 2:30 PM、11:00 AM
- 日期：Sep 13, 2026 或 2026-09-13
- 相对时间：in 30 min, 2 hours ago

### 货币格式

**中文**:
- 人民币：¥1,200 或 1,200 元
- 外币：$100、€80（符号在前）

**英文**:
- 货币符号在前：$100、€80、¥1,200
- 三位逗号分隔：1,200.00

## 7. 按钮文案

### 动词优先

**中文**:
- ✅ "保存"、"取消"、"确认"、"删除"
- ❌ "保存操作"、"进行取消"

**英文**:
- ✅ "Save"、"Cancel"、"Confirm"、"Delete"
- ❌ "Perform Save"、"Do Cancel"

### 按钮长度

**限制**:
- 中文：2-4 个字为佳，最多不超过 6 个字
- 英文：1-2 个单词为佳，最多不超过 3 个单词

**过长的处理**:
- 使用图标 + 短文本
- 移到说明文字中

## 8. 可访问性 (Accessibility)

### 屏幕阅读器友好

**避免**:
- ❌ "点击这里"（无语境）
- ❌ 仅用颜色区分状态

**使用**:
- ✅ "打开菜单"、"关闭对话框"
- ✅ 图标 + 文字标签
- ✅ ARIA 标签：`aria-label="Close dialog"`

### 状态描述

**加载状态**:
- ✅ "加载中，请稍候..."
- ✅ "正在保存您的更改..."

**错误状态**:
- ✅ "无法加载，请重试"
- ✅ 提供具体错误原因

## 9. 本地化注意事项

### 文化敏感

**避免**:
- 政治敏感话题
- 宗教相关内容
- 地域刻板印象

**使用**:
- 中性、包容的语言
- 考虑多元文化背景

### 日期时间

**中文**:
- 年 - 月-日：2026 年 9 月 13 日
- 周几：周一、周二

**英文**:
- 美式：MM/DD/YYYY (09/13/2026)
- 英式：DD/MM/YYYY (13/09/2026)
- ISO: YYYY-MM-DD (2026-09-13)

**建议**: 使用 ISO 格式避免歧义

## 12. 示例对比

### 好的文案 vs 差的文案

**场景：网络错误**

✅ 好:
```
标题：网络连接失败
正文：无法连接到服务器，请检查网络后重试
按钮：重试
```

❌ 差:
```
标题：错误
正文：发生网络相关错误导致无法完成操作
按钮：确定
```

**场景：预订成功**

✅ 好:
```
标题：预订确认
正文：您已成功预订北京饭店，确认邮件已发送至 example@email.com
按钮：查看订单
```

❌ 差:
```
标题：成功
正文：操作已完成
按钮：好的
```
