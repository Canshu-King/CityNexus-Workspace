# DeepSeek Visual UI Review Contract

Input includes a screenshot, viewport, route/screen, intended user goal, and UX rubric. The strict output schema contains `screen`, `overall_score`, severity-tagged hierarchy findings with evidence and fixes, contrast, mobile density, affordance, copy, engineering leakage, and `keep`.

Visual review is advisory. Automated accessibility checks remain authoritative for machine-detectable issues. Vague aesthetic opinions are not auto-applied; each accepted finding requires screenshot evidence, and functionality/test IDs remain stable unless intentionally migrated.
