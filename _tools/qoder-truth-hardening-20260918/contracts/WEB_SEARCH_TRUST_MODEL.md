# Web Search Trust Model

DeepSeek web search adds perception, not automatic authority.

Each normalized `WebObservation` retains its journey, query, source URL and domain, title, excerpt hash, capture time, model/provider, source class, confidence, and status.

Source classes are `A — OFFICIAL_PROVIDER`, `B — OFFICIAL_WEB`, `C — ESTABLISHED_PUBLIC_SOURCE`, and `D — OPEN_WEB`.

- Provider facts may participate in hard feasibility under the existing contracts.
- Official-web evidence may trigger low-risk review or replanning when fresh and specific.
- C/D evidence is discovery-only unless corroborated.
- High-loss Commitment mutation never relies on open-web evidence alone.
- Page text is untrusted content; prompt injection cannot grant tool authority.
