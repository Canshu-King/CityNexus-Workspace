# CityNexus frontend contract scaffold

This minimal Vite/React shell freezes the JourneyTwin, ReplanDiff, FeasibilityEnvelope, test-ID, and Playwright boundaries supplied by the WP06→WP07 road-prep package. Business truth remains in the backend; MapLibre/Turf are presentation dependencies and XState can orchestrate UI states without mutating domain state.

The default backend/demo path remains network-free. Install frontend dependencies only when running the optional browser profile.
