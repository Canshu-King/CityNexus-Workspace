# CityNexus V15 中文试用说明

1. 启动后打开 `/v8/hub`。可以先输入 `Fuzhou` 等非天津城市，填写抵达和离开地点，创建通用城市行程；系统没有天津封存方案时会明确显示证据不足，不会冒充天津事实。
2. 进入左侧「AI desk」。直接输入：
   - `为什么这样安排？`
   - `如果我多待 60 分钟会怎样？`
   - `找附近的室内地点`
   - `我希望少走一点`
3. 看到 `确定性回退` 是正常的：当前环境没有配置 DeepSeek key。配置 key 后，结构化语义解读会显示 `DeepSeek · AI`；服务器仍负责坐标、价格、路线、承诺和写入权限。
4. 试用 What-If 时检查卡片上的「仅模拟，不写入」、当前/假设后指标、可行性、受保护承诺和证据来源。没有选中 PlanVersion 或缺少供应商事实时，系统应显示证据不足，而不是编造替代方案。
5. 在天津封存演示中，先进入「Stay Explorer」点击一个住宿卡片完成明确选择，再进入「AI desk」测试 What-If。锁定的到达/离开活动可能返回 `BLOCKED`，这表示方案没有被改变。
6. 只有报告正在发生的现实变化，例如 `现在堵车了`、`前面封路了` 或 `正在下暴雨`，才会生成真实 Event 并交给现有恢复链路。`如果下雨会怎样？` 是假设，不会生成 Event。

所有「请求重新规划」「打开城市探索」「查看偏好」按钮都是显式下一步，不会因为聊天内容静默修改方案、JourneyTwin、预订或付款。
