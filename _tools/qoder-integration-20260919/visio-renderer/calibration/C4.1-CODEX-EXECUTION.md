## Non-negotiable mechanics

- Native Microsoft UML `Association` master remains the connector.
- One semantic relation = one native Association shape.
- Endpoints glue to explicit instance connection points.
- Connection points carry outward DirX/DirY direction vectors.
- Do not glue to `PinX`.
- On the connector instance override the inherited stock master values:
  - `ShapeRouteStyle = 1` (right angle)
  - `ConLineRouteExt = 0` (do not force the stock straight extension)
  - `ConFixedCode = 2` when available (never reroute)
- Temporarily use `Page.LayoutRoutePassive = True` when available so endpoint glue does not trigger advanced rerouting while manual geometry is installed.
- Glue first, then write Geometry1.
- Geometry1 points must be converted from page coordinates through the connector's effective `PinX/PinY/LocPinX/LocPinY/Angle` transform.
- Do not use `min(x), min(y)` as the connector-local origin.
