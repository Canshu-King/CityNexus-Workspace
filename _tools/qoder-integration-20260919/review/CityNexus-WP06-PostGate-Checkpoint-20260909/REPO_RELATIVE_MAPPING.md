# Repo-relative mapping

Extract this checkpoint at the CityNexus repository root. Every implementation artifact retains its repository-relative path.

- `.env.example`
- `backend/pyproject.toml`
- `backend/app/**`
- `backend/db/**`
- `backend/data/**`
- `backend/tests/**`
- `contracts/**`
- `data/**`
- `requirements/**`

Review-only source material is under `review_contract/` and must not be overlaid onto the repository as implementation files.

No hash manifest is included or required.
