# GitHub Adoption

Material adoption is recorded in `docs/frontend/THIRD_PARTY_ADOPTION_V11.md`.
V11 materially uses dnd-kit for Trip Studio, TanStack Query for server state,
OpenAPI TypeScript generated operation types, Lucide icons, Storybook, React
Hook Form, and Zod. An optional SearXNG adapter is implemented without making
SearXNG a deployment requirement. 21st MCP was used for component search and
alternatives; no unclear-license source was copied.
