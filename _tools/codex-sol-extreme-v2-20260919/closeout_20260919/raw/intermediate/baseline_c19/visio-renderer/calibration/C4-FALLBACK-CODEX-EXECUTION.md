# C4 fallback calibration contract

Frozen state: C1, C2 and C3 are `FROZEN_PASS`; C4 remains `BLOCKED` pending
external review.

The fallback keeps one native Microsoft UML Association per semantic route,
with live endpoint glue, source/target metadata and `LinePattern = 0` to hide
only its stroke. The visible route is drawn as deterministic, unglued
`DrawLine` presentation segments from the approved calibration waypoints.

Run only:

```powershell
python -m pytest .\tests -q
python .\calibration\build_c4_fallback.py
python .\calibration\validate_c4_fallback.py
```

The independent validator must verify native semantic Associations, glue and
directional ports, exact presentation segment geometry and style, zero
crossings/overlaps/through-node/out-of-page errors, and no ShapeSheet error
tokens. Stop after this calibration; do not render formal Phase 1, RC6 or Part 2.
