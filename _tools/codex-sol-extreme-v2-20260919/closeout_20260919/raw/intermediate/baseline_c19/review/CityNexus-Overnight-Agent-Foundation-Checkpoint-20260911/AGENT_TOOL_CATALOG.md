# Agent Tool Catalog

The runtime catalog is generated by `backend/app/agent/tool_catalog.py` and
is also served by `GET /api/v1/agent/tools`.

1. `inspect_journey`
2. `inspect_twin`
3. `list_replans`
4. `search_city_services`
5. `request_replan`
6. `accept_replan`

The MCP adapter uses the same allowlist. Payment, refund, C4 modification,
policy mutation, arbitrary HTTP/SQL, terminal, file, and browser tools are not
registered.
