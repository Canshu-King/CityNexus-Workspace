# Requirements Infrastructure

This directory is an empty, validation-ready foundation for the CityNexus requirements phase. No concrete requirements have been authored at the baseline-freeze stage.

The six requirement sections are intentionally empty. Future entries must use the namespaces `BG`, `FR`, `BR`, `NFR`, `SR`, or `IR`. Domain-model rules use `DR-xxx`; they are not requirements `BR-xxx` identifiers.

`validate-requirements.py` loads the approved domain model dynamically for domain-element reference checks and enforces the fixed use-case set UC-01 through UC-13.
